## 🚀 Featured Projects

### 🧠 [MindSahayak](https://github.com/PSKprem/MindSahayak): Youth Mental Health Support & Detection
An AI-powered, **multilingual** mental-health companion for Indian students.
- Uses **Google Gemini + LangChain** with persistent conversation memory in **MongoDB**
- Real-time **emotion detection** and a **crisis module** that connects high-risk users to localized helplines

`Python` `Flask` `Google Gemini` `LangChain` `MongoDB` `Hugging Face` `REST API`

### 📱 Knowledge Distillation for On-Device Image Classification *(private repo)*
Compressed a **ResNet-50 teacher (85.46% top-1)** into small **MobileNet students** for phones on **CIFAR-100**, and studied the accuracy-vs-model-size trade-off.
- Distillation improved every student on every seed, by up to **+1.70 pp** (MobileNetV2 w1.4: 82.36% → 84.06%, 3 seeds)
- Exported models to **ONNX and TFLite** and applied **INT8 quantization**: MobileNetV2 w0.5 went from 3.12 MiB to 1.00 MiB with 74.67% accuracy against 75.03% in FP32

`Python` `PyTorch` `TensorFlow Lite` `ONNX` `Knowledge Distillation` `Quantization`

### ⚖️ High Court Case Information Portal · [Live Demo](https://prp-high-court-project.netlify.app/)
A case-information portal with **search by case type, name and number**, detailed case histories and downloadable PDFs, plus **interactive analytics charts**.

`Python` `Flask` `FastAPI` `HTML` `CSS` `JavaScript` `BeautifulSoup` `Selenium`

### 📈 [Stack Overflow Technologies Analysis](https://github.com/PSKprem/StackOverflow_Tag_Analysis)
Scraped Stack Overflow tags (2022 to 2025) and visualised **monthly technology usage trends**.

`Python` `BeautifulSoup` `Chart.js` `Pandas`

### 🕸️ [LinkedIn Network Analyser](https://github.com/PSKprem/MFC-LinkedIn-graph)
Turned LinkedIn connection CSVs into a **social network graph** and applied **centrality metrics** to find key users and influence patterns.

`Python` `Pandas` `Graph Algorithms` `Matplotlib` `JSON`
